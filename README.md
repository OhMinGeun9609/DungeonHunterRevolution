유니티 심화과정 개인과제 DungeonHunterRevolution

게임소개
3D 탑뷰(?) 시점의 방치형 rpg게임입니다.
플레이어는 자동으로 이동하며 마주치는 적들을 자동으로 공격, 섬멸합니다.
모든 적을 섬멸하면 스테이지가 클리어 되고, 그에 따른 보상을 얻습니다.

현재 완성도
: 40% (미완)

기능 설명
스테이터스 표시 : 플레이어의 스탯을 표시합니다.

인벤토리 기능 : 인벤토리에서 플레이어가 보유한 아이템을 확인할 수 있습니다.
아이템의 종류는 장비아이템과 소비아이템으로 구분되어 있습니다.

장착, 소비 기능 (미완) : 장착버튼, 소비아이템 데이터 개발 전

스테이지 (현재 미완, 테스트용 스테이지만 존재)
전투시스템(미완) : 플레이어와 적 오브젝트는 서로를 인식하는 순간 전투모드에 돌입하여 경로를 서로의 현재 위치로 변경합니다.

- AI 네비게이션 사용
- TileMap사용 (테스트용 스테이지 제작)
